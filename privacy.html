01. 적용 범위

Sall Dashboard는 운영자의 컴퓨터에서 실행하는 개인용 콘텐츠 제작·운영 앱입니다. 이 방침은 앱의 Google Ads 키워드 조사와 Google 계정을 연결하는 YouTube 기능을 포함한 데이터 처리에 적용됩니다. 각 기능은 사용자가 설정하거나 연결한 서비스와 권한 범위에서 동작합니다.

공개 안내 홈페이지에서는 앱 기능과 개인정보처리방침을 열람할 수 있습니다. 이 홈페이지에는 Google 계정 연결, 인증 정보 입력, 파일 업로드 기능이 없습니다.

02. 접근하는 정보와 이용 목적

키워드 및 블로그 조사
입력한 블로그·경쟁 글 주소, 공개 글의 제목·주소·발췌, 검색어 후보와 자동완성 자료를 조사에 사용합니다. Google Ads API의 키워드 아이디어, 월간 검색량, 광고 경쟁도와 입찰가 지표를 조회해 주제 선정과 콘텐츠 전략에 활용합니다. API 요청에는 연결된 Google Ads 고객 계정 식별자와 인증 정보가 사용됩니다.
Google 인증 정보
승인된 기능의 API 요청을 수행하기 위해 액세스 토큰, 갱신 토큰 등 해당 기능에서 필요한 인증 정보를 사용합니다. 인증 정보는 공개 홈페이지에 게시하지 않습니다.
YouTube 채널 관리
연결된 채널의 식별자·이름·썸네일, 영상 정보, 시청 및 수익 분석 정보를 채널 관리에 사용합니다. 사용자가 요청한 영상 업로드·썸네일 설정·재생목록 작업에는 필요한 영상 파일과 제목·설명·기타 설정이 사용됩니다.
문의
이메일 문의 시 발신자의 이메일 주소와 문의 내용을 답변 및 요청 처리에 사용합니다. 인증 토큰이나 비밀번호를 문의 이메일로 보내지 마세요.

03. 저장 위치와 보관

앱의 작업 기록, 콘텐츠 파일과 연결 정보는 운영자의 컴퓨터에 저장됩니다. YouTube 연결 정보와 갱신 토큰은 로컬 저장소에 보관됩니다. Google Ads 인증은 로컬 환경에 설정된 Google 인증 정보를 이용합니다. 키워드 조사 결과와 실행 기록은 화면에 표시되며 사용자가 파일로 저장할 수 있습니다.

로컬 데이터는 운영자가 해당 기록·연결·파일을 삭제할 때까지 보관될 수 있습니다. 외부 서비스에 전송된 정보의 보관에는 각 서비스의 정책과 계정 설정이 적용됩니다. 문의 이메일은 요청 처리를 위해 보관되며 삭제를 요청할 수 있습니다.

Google API 통신은 HTTPS를 이용합니다. 로컬 파일과 인증 정보의 접근 권한은 운영자의 컴퓨터 및 계정에서 관리합니다.

04. 외부 서비스로 전송되는 정보

  • Google Ads: 인증 정보, 계정 식별자와 키워드 후보를 지표 조회를 위해 API에 전송합니다.
  • Google 검색 자동완성 및 입력한 공개 웹사이트: 검색어 또는 요청한 주소로 조회 요청을 보냅니다.
  • Google Vertex AI Gemini: 키워드 콘텐츠 전략을 생성할 때 공개 블로그·경쟁 글 자료, 자동완성 검색어와 선정된 키워드 지표를 전송합니다.
  • YouTube 및 Google의 관련 API: 인증 정보와 조회·업로드·채널 분석에 필요한 요청 정보가 전송됩니다. 업로드 기능을 사용할 때 선택한 콘텐츠 파일이 전송됩니다.
  • 연결된 워드프레스 및 설정한 콘텐츠 생성 서비스: 사용자가 요청한 글 생성·발행에 필요한 입력 자료와 콘텐츠를 전송합니다. 이용하는 서비스는 앱의 설정과 기능에 따라 달라집니다.

외부 서비스 처리는 각 제공자의 운영 환경에서 이루어지며 해외에서 처리될 수 있습니다. 인증 토큰을 공개 홈페이지나 키워드 전략 생성 프롬프트에 포함하지 않습니다.

05. Google 사용자 데이터 이용 원칙

Sall Dashboard의 Google API에서 받은 정보 이용 및 다른 앱으로의 전송은 Google API Services User Data Policy와 해당되는 제한적 사용(Limited Use) 요건을 따릅니다.

  • Google 사용자 데이터는 사용자가 요청한, 앱에 표시된 기능을 제공하는 목적으로 사용합니다.
  • Google 사용자 데이터를 판매하거나 맞춤 광고·광고 타기팅에 이용하지 않습니다.
  • Google 사용자 데이터를 일반적인 AI 모델의 학습·훈련 목적으로 사용하지 않습니다.
  • 전송은 요청한 기능 제공에 필요한 범위에서 수행합니다. 그 밖의 제공은 이용자의 동의, 보안 대응 또는 법적 의무 등 Google 정책이 허용하는 경우로 제한합니다.

06. 연결 해제와 데이터 삭제

Google 계정의 서드 파티 연결 관리에서 Sall Dashboard의 접근 권한을 철회할 수 있습니다. YouTube 연결은 앱의 연결 관리에서 삭제할 수 있으며, 해당 로컬 연결 레코드와 갱신 토큰이 삭제됩니다.

권한 철회나 채널 연결 삭제만으로 기존 콘텐츠 파일·분석 기록·백업이 모두 삭제되지는 않습니다. 저장한 결과 파일과 로컬 작업 기록은 별도로 삭제해야 하며, Google Ads의 로컬 인증 정보도 해당 인증 환경에서 제거해야 합니다. Google이나 YouTube에 이미 게시한 콘텐츠는 해당 서비스에서 별도로 관리·삭제할 수 있습니다.

운영자가 보관하는 데이터에 대한 열람·수정·삭제 문의는 아래 연락처로 보낼 수 있습니다. 삭제를 요청할 때 관련 기능과 대상 기록을 알려주세요.

07. 공개 홈페이지 방문 정보

이 홈페이지는 GitHub Pages에서 제공하는 정적 안내 사이트입니다. 자체 회원가입, 입력 양식, 광고·분석 추적 스크립트, 앱에서 설정하는 쿠키를 사용하지 않습니다.

호스팅 제공자인 GitHub는 사이트 제공과 보안을 위해 방문자의 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침에서 확인할 수 있습니다.
