하나의 작업 공간

조사에서 운영까지,
필요한 흐름을 연결합니다.

01 / RESEARCH

키워드 조사

공개된 블로그 글과 검색어 후보를 살펴보고, Google Ads API의 키워드 아이디어·월간 검색량·광고 경쟁도 지표를 콘텐츠 주제 선정에 활용합니다.

광고 경쟁도는 자연 검색의 SEO 난이도와 구분합니다.

02 / PUBLISHING

블로그 제작과 발행

연결된 워드프레스 블로그의 글 작성과 발행 작업을 관리합니다. 키워드 조사 자료를 바탕으로 글의 방향과 구성을 정리합니다.

콘텐츠 생성 기능은 설정된 외부 AI 서비스를 이용할 수 있습니다.

03 / CHANNELS

YouTube 채널 관리

사용자가 연결한 채널과 영상 정보, 조회·수익 분석을 확인하고 요청한 영상 업로드와 콘텐츠 작업을 관리합니다.

Google 계정에서 승인한 권한으로 해당 기능을 사용합니다.

데이터와 연결

내 환경에서 작업하고,
필요한 서비스와 연결합니다.

앱의 작업 데이터와 연결 정보는 운영자의 컴퓨터에 저장됩니다. 키워드 지표 조회, 콘텐츠 생성, 채널 조회와 업로드를 수행할 때 필요한 정보가 해당 외부 서비스로 전송됩니다.

어떤 정보를 이용하고 어디로 전송하는지, 연결을 해제하고 데이터를 삭제하는 방법은 개인정보처리방침에서 확인할 수 있습니다.
